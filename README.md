# Minecraft-Dev-Page

## Vercel Hosting

This site is static, so Vercel can host it without a build step.

1. Install the Vercel CLI if you want a local preview.
2. Run `vercel` from the project root to create and link the deployment.
3. Push changes normally after the project is linked.

The dashboard reads live telemetry directly from the Minecraft APIs and stores snapshot history in browser localStorage for the charts.
